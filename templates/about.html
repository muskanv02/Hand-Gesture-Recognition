ABOUT THE PROJECT

About GestureAI

A computer vision and machine learning based hand gesture recognition system designed for real-time interaction.

What is GestureAI?

GestureAI is a real-time hand gesture recognition web application that uses computer vision and machine learning to understand hand movements.

The application captures video through a webcam, detects hand landmarks using MediaPipe and passes the extracted features to a trained Random Forest classification model.

The predicted gesture is then displayed instantly on the Live Recognition dashboard, making the system simple, interactive and easy to use.

Project Objective

The main objective of this project is to demonstrate how artificial intelligence and computer vision can be used to create a natural and interactive method of communication between humans and computers.

  • Real-time hand detection
  • Machine learning based classification
  • Multiple gesture recognition
  • Interactive web dashboard
