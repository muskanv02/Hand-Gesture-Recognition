# Hand Gesture AI - Multi Page

Pages:
- Home
- Live Recognition
- How It Works
- About
- Contact

Install:
pip install -r requirements.txt

Collect data:
python collect_data.py

Train:
python train_model.py

Run:
python app.py

Open:
http://127.0.0.1:5000

Note: This version uses MediaPipe Hands API and does not require hand_landmarker.task.
